# Личный финансовый трекер

## О проекте
Веб-приложение для учета личных доходов и расходов, позволяющее пользователям контролировать свой бюджет, анализировать по категориям за различные временные периоды и формировать отчеты.

### Ключевые функции:
1. Регистрация операций с указанием суммы, даты и комментария.
2. Управление категориями.
3. Фильтрация и поиск операций по периодам.
4. Формирование отчетов.
5. Экспорт финансовой истории.

### Ключевые сущности:
* **Пользователь**: ID, имя, email, хэш пароля.
* **Категория**: ID, название, тип.
* **Финансовая операция**: ID, тип, сумма, дата совершения, категория_ID, комментарий.
* **Бюджетный отчет**: суммы за период по категориям.
